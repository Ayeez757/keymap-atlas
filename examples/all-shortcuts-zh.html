7 · 无法静态枚举的层

层为什么读不出来怎么查
Firefox / Chromium / Electron 应用内快捷键编译进程序或存在 profile 的加密库里，没有统一的导出接口菜单 → 帮助 → 键盘快捷键；Firefox 也可在 about:config 搜 key_ 前缀
GTK / Qt 的 .ui 文件与代码里的 accel散布在源码与资源包里，运行期才注册，没有枚举 API应用内「快捷键」设置页；或 grep accel 对应的 .ui 文件
键盘固件里的 Fn 组合（如 Fn+F1 调亮度）由键盘控制器自己处理，操作系统完全看不到；只能按一下看有没有反应查键盘说明书；或 sudo libinput debug-events --show-keycodes 实测
浏览器扩展的快捷键存在各扩展自己的存储里，需要逐个读取扩展数据目录扩展自己的快捷键设置页
Wayland 的 xdg-desktop-portal GlobalShortcuts按会话／应用隔离：对其他应用的会话调用 ListShortcuts 会被 Access deniedbusctl --user tree org.freedesktop.portal.Desktop 能看到会话属主，读不到内容
Flatpak / Snap 应用的自定义键沙箱有自己的配置目录，路径与宿主不同进 flatpak run --command=sh 的应用沙箱里看 ~/.config
